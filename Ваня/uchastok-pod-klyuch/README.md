# Рекламный ролик «Участок под ключ»

Готовое видео: **`uchastok-pod-klyuch.mp4`** — вертикальное 9:16, 1080×1920, 30 кадров/с,
20,5 с, H.264, **без звуковой дорожки** (для истории MAX).

| Время | Сцена | Надпись |
|---|---|---|
| 0–3 с | Заросший участок, наезд камеры, метка «ДО» | УЧАСТОК ЗАРОС? / ПРИВЕДЁМ В ПОРЯДОК |
| 3–6 с | Бензиновый триммер, боковая проводка камеры | ПОКОС ТРАВЫ |
| 6–9 с | Спил в каске, маске и перчатках | СПИЛ ДЕРЕВЬЕВ |
| 9–12 с | Погрузка веток в прицеп | СБОР И ВЫВОЗ ВЕТОК |

| 15–17 с | Один и тот же участок: шторка «ДО / ПОСЛЕ» | БЫЛО → СТАЛО / УЧАСТОК ПОД КЛЮЧ |
| 17–20,5 с | Финальный экран (номер полностью виден 3 с) | ВЕРНЁМ УЧАСТКУ ПОРЯДОК / ЗВОНИТЕ ПРЯМО СЕЙЧАС / 89995511488 |

## Состав папки

- `scenes/` — фотореалистичные кадры сцен без текста (сгенерированы по `brief/prompt_video_ru.txt`
  с учётом `brief/negative_prompt_ru.txt`; кадр «после» сделан на основе кадра «до», поэтому дом,
  забор и ракурс совпадают).
- `render.py` — сборка ролика: виртуальная камера (наезды, панорамы, лёгкая «ручная» тряска в рабочих
  сценах), перекрёстные переходы, шторка до/после и анимированные надписи. Текст накладывается
  программно, поэтому русские буквы и номер телефона без искажений.
- `fonts/` — шрифты Noto Sans Display и Inter (лицензия SIL OFL).
- `preview/` — ключевые кадры для быстрой проверки.
- `brief/` — исходное ТЗ и референс.

## Пересборка

```bash
pip install pillow numpy      # нужен также ffmpeg с libx264
python3 render.py --preview   # ключевые кадры в preview/
python3 render.py             # uchastok-pod-klyuch.mp4
```

Тексты, тайминги и номер телефона (`PHONE`) задаются в `render.py`.
